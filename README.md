# Operating Systems Lab Experiments

## About
This repository contains the practical experiments performed as part of the Operating Systems (OS) laboratory in the B.Tech Computer Science and Engineering (AIML) program at Model Institute of Engineering and Technology (MIET), Jammu.

The experiments cover basic Linux commands, shell scripting, process management, memory management, and system monitoring using C programming.

## Technologies Used
- Linux Operating System
- Bash Shell Scripting
- C Programming
- GCC Compiler
- Linux Commands and Utilities

## List of Experiments
| 1 | Basic Bash commands, I/O redirection, pipes, file and directory operations, searching files, process management and vi/nano editor commands. 
| 2 | Date and who commands, output redirection and sed command to swap the first and second words in each line. 
| 3 | Shell scripts to check whether an argument is a file or directory and convert filenames to uppercase. 
| 4 | Shell scripts to determine user working time, display specific lines from a file and delete lines containing a specified word. 
| 5 | String operations using Shell Script and C: substring extraction, string length and execution time comparison. 
| 6 | C program to allocate memory using command-line arguments and observe memory usage using the free command. 
| 7 | CPU-bound and I/O-bound C programs and observation of CPU share using the top command. 
| 8 | Understanding process memory maps using the pmap command. 
| 9 | C program to create a child process, wait for its termination and display its PID. 
| 10 | C program to print the address of a variable and observe memory address values using multiple processes. 

## Learning Outcomes
- Understanding Linux commands and shell scripting.
- Learning file handling and process management.
- Understanding process creation and termination.
- Learning memory allocation and memory mapping.
- Understanding CPU utilization and process scheduling.
- Developing basic system programming skills using C.

## How to Run

### For C Programs
Compile using GCC:

```bash
gcc filename.c -o output
```

Run:

```bash
./output
```

### For Shell Scripts

Give execution permission:

```bash
chmod +x filename.sh
```

Run:

```bash
./filename.sh
```

## Conclusion
These experiments provide practical knowledge of operating system concepts, Linux commands, shell scripting, process management, CPU scheduling and memory management.
